# PexisLink benchmark (quick profile, dev split)

> Synthetic data generated by the same project that wrote the detector. These numbers verify behaviour against documented assumptions; they are not evidence of real-world accuracy and say nothing about failure prediction.

- Seeds: [101, 102]; 8 vehicles per scenario; 6 reference days then 14 evaluation days per vehicle.
- pexislink 0.2.0a0, Python 3.11.17, code sha256 `4a1d31fce48ba1dd`.
- 95 % intervals: bootstrap over vehicles (1000 resamples, fixed seed). For zero false alerts the exact Poisson bound is shown, which assumes independent alerts. N/A means not applicable, never zero.
- Detection is direction-aware: overheat must be reported *above* reference, stuck-open thermostat *below*, drift in the sign of its rate. Abrupt faults count only if detected within 24 h of onset.
- **Placebo recall**: the same windows and directions on fault-free control vehicles; excess recall = recall - placebo recall. A detection claim needs excess recall clearly above 0.
- False alerts are counted per 1000 *eligible* operating hours (outside fault intervals) and per eligible trip. Misdirected alerts (inside a fault interval, wrong direction) are counted separately.
- Hypothesis criteria: coverage floor 0.2, non-inferiority margin 0.1 on excess recall.

## Detectors

- `fixed-limit-115C`: naive warning light: >= 115 C for 2 consecutive samples; no reference, time or quality logic
- `v0.1-as-shipped`: frozen v0.1 rule on raw rows; the run fails if v0.1 rejects any row
- `v0.1-cleaned`: frozen v0.1 rule after oracle-free cleaning (drop unparseable rows, sort, de-duplicate)
- `v0.2`: defaults (ADR 0001 §4, corrected after review in §7)
- `v0.2-no-warmup`: ablation: warm-up suppression off
- `v0.2-fixed-8C`: ablation: v0.1's fixed 8 C threshold
- `v0.2-fixed-4C`: ablation: plain fixed 4 C threshold (what does the robust scale add?)
- `v0.2-no-load`: ablation: engine-load context ignored
- `v0.2-no-absolute`: ablation: absolute 115 C barrier off
- `v0.2-no-stuck`: ablation: stuck-sensor rule off
